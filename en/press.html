Pilmil Studio in brief

Pilmil Studio publishes six free, open-source apps for Android, under the MPL-2.0 licence. They work without an account, without trackers and without permission to access the Internet. Each feature rests on published research or on a stated design choice, and each website says which.

The six apps

  • Respire

    One breath before endless scrolling. Website · Source code · APK

  • Sommelle

    Recover your sleep, week after week. Website · Source code · APK

  • Lunaison

    Your cycle, for your eyes only. Website · Source code · APK

  • Sillon

    A vegetable garden that follows your climate. Website · Source code · APK

  • Sauve

    The right steps, even when panic sets in. Website · Source code · APK

  • Fredonne

    A melody written, heard and transposed. Website · Source code · APK

Availability

The apps are available as APKs, from the releases page of each GitHub repository. The iPhone versions are in development.

Icons and screenshots

The icon of each app is in the img/apps folder of the website. Screenshots and visuals are in the docs/marketing folder of each repository, at github.com/Pilmil-Studio.

How they are made

Pilmil Studio is a French non-profit association (loi 1901, registration in progress), and the code is written with the help of an AI assistant, then reviewed and maintained by its members.
